# deno_supabase

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A sample web application demonstrating how to use Deno with a Supabase backend. It features a basic event posting board where users can create new posts and "join" them, incrementing a participant counter.


![A screenshot of the deno_supabase application interface. On the left, there is a form with fields for "Username", "Title", "Date", and "Description". On the right, there is a list of posts, each showing a title, creator, date, and participant count, along with a "Join" button.](https://user-images.githubusercontent.com/3233328/171906910-9098b628-4158-4513-9bb6-a33a59e51c86.png)


## Features

-   **Create & View Posts:** Add new posts/events through a simple web form and view all existing posts.
-   **Update Participants:** "Join" an event to atomically increment its participant count in the database.
-   **Deno Backend:** Built with Deno's native HTTP server and standard library modules.
-   **Supabase Integration:** Uses the `supabase-js` library to interact with a PostgreSQL database on Supabase.

## Tech Stack

-   **Runtime:** [Deno](https://deno.land/)
-   **Backend:** [Supabase](https://supabase.com/) (Database)
-   **Frontend:** HTML, CSS, Vanilla JavaScript

## Getting Started

Follow these instructions to get the project running on your local machine.

### Prerequisites

-   [Deno](https://deno.land/) (v1.20.0 or higher) installed.
-   A [GitHub](https://github.com/) account.
-   A [Supabase](https://supabase.com/) account and a new project created.

### 1. Clone the Repository

```sh
git clone https://github.com/supabase-community/deno_supabase.git
cd deno_supabase
```

### 2. Set up Supabase

1.  **Create the `post` Table**
    In your Supabase project's SQL Editor, run the following query to create the necessary table:

    ```sql
    create table public.post (
      id bigint generated by default as identity primary key,
      username text,
      title text,
      date timestamptz,
      description text,
      participants numeric default 0,
      created_at timestamptz default now()
    );
    ```

2.  **Disable Row Level Security (RLS)**
    For this simple example, RLS is disabled.
    -   Go to the **Authentication** -> **Policies** page in your Supabase dashboard.
    -   Find the `post` table and click **Disable RLS**.

    *Note: For a production application, you should keep RLS enabled and create appropriate security policies.*

### 3. Configure Environment Variables

This project uses a `.env` file to manage Supabase credentials locally.

1.  Create a file named `.env` in the root of the project.
2.  Add your Supabase Project URL and anon key to the file:

    ```
    SUPABASE_URL="YOUR_SUPABASE_URL"
    SUPABASE_KEY="YOUR_SUPABASE_ANON_KEY"
    ```

    You can find these values in your Supabase project's **Settings** -> **API** page.

### 4. Run Locally

Run the server using the Deno CLI. The required permissions for network access, environment variables, and file reading will be prompted, or you can grant them with flags.

```sh
deno run --allow-net --allow-env --allow-read server.js
```

Open your browser and navigate to [http://localhost:8000](http://localhost:8000).

### 5. Deploy to Deno Deploy (Optional)

You can deploy this application to the edge with [Deno Deploy](https://deno.com/deploy).

1.  Fork this repository to your GitHub account.
2.  Sign in to Deno Deploy with your GitHub account.
3.  Create a new project and link it to your forked repository.
4.  Select `server.js` as the entry point.
5.  In the project settings on Deno Deploy, add the `SUPABASE_URL` and `SUPABASE_KEY` as environment variables.
