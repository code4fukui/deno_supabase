# deno_supabase

DenoとSupabaseバックエンドを組み合わせて使用する方法を示すサンプルウェブアプリケーションです。ユーザーが新しい投稿を作成したり、イベントに「参加」して参加者数を増やしたりできる、シンプルなイベント掲示板を備えています。

![deno_supabaseアプリケーションインターフェースのスクリーンショット。左側には「Username」「Title」「Date」「Description」のフィールドを持つフォームがあり、右側にはタイトル、作成者、日付、参加者数、および「Join」ボタンが表示された投稿一覧が並んでいます。](https://user-images.githubusercontent.com/3233328/171906910-9098b628-4158-4513-9bb6-a33a59e51c86.png)

## 機能

-   **投稿の作成と表示:** シンプルなウェブフォームを通じて新しい投稿やイベントを追加し、すべての既存の投稿を表示します。
-   **参加者の更新:** イベントに「参加」して、データベース内の参加者数をアトミックに増加させます。
-   **Denoバックエンド:** DenoのネイティブHTTPサーバーと標準ライブラリモジュールを使用して構築されています。
-   **Supabase統合:** `supabase-js`ライブラリを使用して、Supabase上のPostgreSQLデータベースと連携します。

## 技術スタック

-   **ランタイム:** [Deno](https://deno.land/)
-   **バックエンド:** [Supabase](https://supabase.com/) (データベース)
-   **フロントエンド:** HTML, CSS, Vanilla JavaScript

## はじめに

このプロジェクトをローカルマシンで実行するには、以下の手順に従ってください。

### 前提条件

-   [Deno](https://deno.land/) (v1.20.0以上) がインストールされていること。
-   [GitHub](https://github.com/)アカウント。
-   [Supabase](https://supabase.com/)アカウントと、作成済みの新しいプロジェクト。

### 1. リポジトリのクローン

```sh
git clone https://github.com/supabase-community/deno_supabase.git
cd deno_supabase
```

### 2. Supabaseのセットアップ

1.  **`post`テーブルの作成**
    SupabaseプロジェクトのSQLエディタで、以下のクエリを実行して必要なテーブルを作成します:

    ```sql
    create table public.post (
      id bigint generated by default as identity primary key,
      username text,
      title text,
      date timestamptz,
      description text,
      participants numeric default 0,
      created_at timestamptz default now()
    );
    ```

2.  **行レベルセキュリティ (RLS) の無効化**
    このシンプルな例では、RLSを無効にしています。
    -   Supabaseダッシュボードの **Authentication** -> **Policies** ページに移動します。
    -   `post`テーブルを見つけ、**Disable RLS** をクリックします。

    *注: 本番環境のアプリケーションでは、RLSを有効にしたままにし、適切なセキュリティポリシーを作成する必要があります。*

### 3. 環境変数の設定

このプロジェクトでは、ローカルでのSupabaseの認証情報を管理するために`.env`ファイルを使用します。

1.  プロジェクトのルートに`.env`という名前のファイルを作成します。
2.  ファイルにSupabaseのプロジェクトURLとanonキーを追加します:

    ```
    SUPABASE_URL="YOUR_SUPABASE_URL"
    SUPABASE_KEY="YOUR_SUPABASE_ANON_KEY"
    ```

    これらの値は、Supabaseプロジェクトの **Settings** -> **API** ページで確認できます。

### 4. ローカルでの実行

Deno CLIを使用してサーバーを起動します。ネットワークアクセス、環境変数、ファイル読み取りに必要な権限がプロンプトで求められます。または、フラグを使用してこれらを付与することもできます。

```sh
deno run --allow-net --allow-env --allow-read server.js
```

ブラウザを開き、[http://localhost:8000](http://localhost:8000) にアクセスします。

### 5. Deno Deployへのデプロイ (オプション)

このアプリケーションは、[Deno Deploy](https://deno.com/deploy)を使用してエッジにデプロイできます。

1.  このリポジトリを自身のGitHubアカウントにフォークします。
2.  GitHubアカウントでDeno Deployにサインインします。
3.  新しいプロジェクトを作成し、フォークしたリポジトリにリンクします。
4.  エントリポイントとして `server.js` を選択します。
5.  Deno Deployのプロジェクト設定で、環境変数として `SUPABASE_URL` と `SUPABASE_KEY` を追加します。
